# Сервис аналитики продаж

WPF-приложение для анализа продаж, товаров и выручки.

## Цель проекта
Разработка системы для учёта продаж, расчёта статистики и формирования отчётов.

## Функциональность
- Управление товарами и категориями
- Учёт продаж с выбором клиента
- Фильтрация продаж по дате
- Расчёт общей выручки и среднего чека
- Определение самого продаваемого товара
- Формирование и сохранение отчётов

## Технологии
- C# / WPF
- PostgreSQL
- Npgsql
- MSTest

## База данных
Таблицы: `Users`, `Categories`, `Products`, `Clients`, `Sales`, `Reports`

## Установка и запуск

### Требования
- Visual Studio 2022
- PostgreSQL 15+
- .NET 8.0/9.0

### Шаги
1. Клонировать репозиторий
2. Создать базу данных `SalesDB` в pgAdmin 4
3. Выполнить SQL-скрипт из файла `database.sql`
4. Открыть проект в Visual Studio
5. Запустить (F5)

## Тестирование
- Фреймворк: MSTest
- Количество тестов: 13
- Запуск: Test Explorer в Visual Studio
